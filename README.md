# Retail Transactions Analysis

This project involves analyzing retail transaction data to uncover insights about customer behavior, sales trends, and product performance. The analysis aims to help retailers make data-driven decisions to optimize inventory, marketing strategies, and overall business operations.

## Project Overview

- **Data Source:** Retail transaction records including sales, returns, and customer information.
- **Objectives:**
  - Identify top-selling products and categories.
  - Analyze customer purchasing patterns.
  - Detect seasonal trends and sales fluctuations.
  - Provide actionable recommendations for business improvement.
- **Dashboard:** Build an interactive dashboard using Streamlit to visualize key sales and customer metrics.

## Features

- View total sales and transaction trends by city.
- Analyze year-over-year performance.
- Assess customer responsiveness to promotions using scatter plots and segment buckets.

## Installation

You can install the dependencies using pip:

```
pip install -r requirements.txt
```

## Running the Streamlit App

To launch the Streamlit dashboard:

```
streamlit run streamlit_app/app.py
```

Ensure the `.env` file is set up with any necessary environment variables, such as database credentials.
